# Shared style guide (included by other skills, not a skill itself)

- Default to a professional, warm, concise tone unless the thread history suggests otherwise.
- Prefer short paragraphs and, where the original message used a list, replying in kind.
- Match the greeting/sign-off style already visible in the user's *sent* messages in the thread,
  if any are present in the thread history.
- Never use filler phrases like "I hope this email finds you well" unless the user's own past
  messages in this thread history use similar phrasing.
- Spell out numbers and dates unambiguously (e.g. "Tuesday, March 3" not "3/3" — timezone
  ambiguity has caused real scheduling mistakes).
